# QQ 空间 · Material 3

- **我的 → QQ 空间**打开自己的个人主页（官网 `/QQ号/main`）；联系人和动态作者打开对方主页。若联系人资料只有 NT UID，会先通过 TIM 解析目标 QQ 号。好友动态是单独入口。
- **打开空间**是右上角的完整空间入口，仍在应用内显示。若内置 WebView 未登录，请在腾讯官方页面登录；桌面浏览器与手机 WebView 不共享登录状态。
- **动态卡片**展示作者头像及已加载的文字、图片、视频和带头像的评论。点图可放大切换；网页提供可直连的视频时可在卡片内播放。
- **点赞、取消赞与评论**在卡片里操作，调用官网自己的处理流程。只有收到状态变化或官网回复成功后才确认；未确认不会自动重发。必要的登录验证和验证码由官网处理。
- **谁点赞了**：点动态上的点赞人数，在应用内查看名单；名单支持按官网分页继续加载。
- **谁看过我**：从自己的个人主页顶栏打开，显示官网访客组件当前返回的记录及访问时间。登录账户不符或访客接口失败时显示错误，不把它当成访客为空。

## 实现边界

好友动态在 `#feed_friend_list`，个人主页动态在 `#QM_Feeds_Iframe` 内的 `.feed-home`。预览最多读取官网已经加载的 30 条动态。互动复用当前 WebView 的官网登录态，不提取、复制或保存 Cookie、令牌或验证码。带权限限制的内容仍由腾讯决定是否可访问。

访客组件的旧页面加载器引用 HTTP 脚本；只从已验证的腾讯资源域名补载对应的 HTTPS 脚本，不全局放开混合内容。名单数据以及点赞分页依赖官网实现；页面改版、会话失效或操作需要额外验证时仍可能无法使用。完整媒体及特殊页面可使用内置的「官网」视图。
